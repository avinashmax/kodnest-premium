# KodNest Premium Build System

A premium, coherent design system for SaaS applications. Built with a "Calm, Intentional, Coherent" design philosophy.

## Features

- **Design Philosophy**: No gradients, no glassmorphism, just solid, confident design.
- **Tech Stack**: Vanilla HTML5, CSS3, ES6 JavaScript (Zero dependencies).
- **Components**:
  - Global Layout (Top Bar, Context Header, Workspace, Panel).
  - Smart Interactions (Copy Prompt, Proof Checklist).
  - Premium Typography & Spacing System.

## How to Run

1.  Clone the repository.
2.  Open `index.html` in your browser OR run a local server:
    ```bash
    python -m http.server 8000
    ```
3.  Navigate to `http://localhost:8000`.
